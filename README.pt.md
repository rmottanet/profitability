# Profitability

## :dart: Sobre o Projeto
Este repositório contém o código-fonte do *frontend* de uma aplicação web desenvolvida no âmbito do **Projeto Integrador** do curso superior. A ferramenta é dedicada ao cálculo e à análise da rentabilidade líquida de investimentos em renda fixa, unindo conceitos de economia, finanças e ciências da computação para apoiar a educação financeira.

A aplicação comunica-se com uma API robusta desenvolvida em **TypeScript** (`backend`), responsável pelo processamento lógico e financeiro. Para detalhes sobre a arquitetura do servidor, consulte o [repositório da API](https://github.com/rmottanet/profitability-api-ts).

> **Nota de Implementação:** Nesta versão académica, o endereço do *backend* encontra-se configurado de forma estática (*hardcoded*) para apontar diretamente para a instância da API em [https://github.com/EconObs/profitability-api-ts](https://github.com/EconObs/profitability-api-ts).

## :hammer_and_wrench: Arquitetura e Recursos

- **Calculadora de Rentabilidade:** Interface interativa desenvolvida para simular e comparar o rendimento líquido de diferentes aplicações de renda fixa.
- **Integração com Dados Reais:** Obtenção dinâmica de índices económicos oficiais diretamente através da API do **Banco Central do Brasil (BCB)**.
- **Abordagens Metodológicas:** O projeto contempla diferentes abordagens de cálculo, cujas versões compiladas e históricos de desenvolvimento podem ser consultados na secção de *Releases*.

## :rocket: Como Utilizar

### Acesso à Aplicação
1. Aceda à página oficial do projeto em [https://econobs.github.io/profitability/](https://econobs.github.io/profitability/).
2. Introduza os parâmetros financeiros da aplicação desejada (taxa, prazo, tipo de contrato).
3. Submeta os dados para visualizar os resultados detalhados da rentabilidade líquida.

## :books: Tecnologias Utilizadas
* **Frontend:** HTML, CSS, JavaScript (Interface de Utilizador)
* **Backend:** TypeScript (API RESTful)
* **Fontes de Dados:** API Oficial do Banco Central do Brasil
