# Profitability

## :dart: About the Project
This repository contains the frontend source code of a web application developed as part of a higher education **Capstone Project** (*Projeto Integrador*). The tool is dedicated to calculating and analyzing the net profitability of fixed-income investments, combining concepts from economics, finance, and computer science to support financial literacy and education.

The application communicates with a robust API developed in **TypeScript** (`backend`), responsible for logical and financial processing. For details regarding the server architecture, please refer to the [API repository](https://github.com/rmottanet/profitability-api-ts).

> **Implementation Note:** In this academic version, the backend URL is statically configured (*hardcoded*) to point directly to the API instance at [https://github.com/EconObs/profitability-api-ts](https://github.com/EconObs/profitability-api-ts).

## :hammer_and_wrench: Architecture and Features

- **Profitability Calculator:** An interactive interface developed to simulate and compare the net yield of various fixed-income investments.
- **Real-Time Data Integration:** Dynamic retrieval of official economic indices directly through the **Central Bank of Brazil (BCB)** API.
- **Methodological Approaches:** The project includes different calculation approaches, whose compiled versions and development histories can be found in the *Releases* section.

## :rocket: How to Use

### Accessing the Application
1. Visit the official project page at [https://econobs.github.io/profitability/](https://econobs.github.io/profitability/).
2. Enter the financial parameters of your desired investment (rate, term, contract type).
3. Submit the data to view detailed results of the net profitability.

## :books: Technologies Used
- **Frontend:** HTML, CSS, JavaScript (User Interface)
- **Backend:** TypeScript (RESTful API)
- **Data Sources:** Official Central Bank of Brazil API
